# Gambar event

Taruh gambar di folder ini dengan nama file persis seperti di bawah (PNG, rasio **16:9**, misalnya 1280×720).
Gambar tampil di bagian atas modal event. Kalau filenya belum ada, modal menampilkan emoji eventnya.

## Acara di stasiun (🎉, stasiun jadi ungu, penumpang membludak)

| File | Mood |
|---|---|
| `konser_musik.png` | Malam, lampu panggung warna-warni, kerumunan mengangkat tangan. Ramai dan meriah. |
| `pertandingan_sepak_bola.png` | Stadion penuh suporter, bendera dan syal, sore yang cerah. Semangat dan riuh. |
| `festival_kuliner.png` | Deretan tenda makanan, asap sate, lampion, orang antre. Hangat dan menggugah selera. |
| `pameran_otomotif.png` | Hall pameran terang, mobil dan motor mengilap, pengunjung memotret. Modern dan berkilau. |
| `pawai_budaya.png` | Pawai di jalan raya: pakaian adat, reog/ondel-ondel, penonton di pinggir jalan. Warna-warni dan bangga. |
